# Changelog

All notable changes to **Build 54 (Styled Components Theme-able UI Kit)** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.8.0] - 2026-07-31

### Added
- Integrated **Styled Dropdown Select Menu Component (`Select.jsx`)**.
- Added custom select dropdown with item icons, selected checkmark indicators (`✓`), disabled states, click-outside dismissal, and rotating chevron animations (`rotate(180deg)`).

## [1.7.0] - 2026-07-30

### Added
- Integrated **Styled Accordion FAQ Component (`Accordion.jsx`)**.

## [1.6.0] - 2026-07-30

### Added
- Integrated **Styled Tooltip Hover Popup Component (`Tooltip.jsx`)**.

## [1.5.0] - 2026-07-30

### Added
- Integrated **Styled Checkbox & Toggle Switch Controls Component (`Checkbox.jsx`, `Toggle.jsx`)**.

## [1.4.0] - 2026-07-30

### Added
- Integrated **Styled Avatar & Avatar Group Component (`Avatar.jsx`)**.

## [1.3.0] - 2026-07-30

### Added
- Integrated **Styled Progress Bar & Skeleton Loader Component (`Progress.jsx`, `Skeleton.jsx`)**.

## [1.2.0] - 2026-07-30

### Added
- Integrated **Styled Tabs Navigation Bar Component (`Tabs.jsx`)**.

## [1.1.0] - 2026-07-30

### Added
- Integrated **Styled Modal Overlay Component (`Modal.jsx`)**.

## [1.0.0] - 2026-07-30

### Added
- Initial release of **Build 54: Theme-able UI Kit using Styled Components (CSS-in-JS)**.
- Implemented **5 Core Theme-Aware Components** (`Button`, `Card`, `Badge`, `Switch`, `Input`).
- Implemented **Light / Dark Theme Tokens** (`lightTheme`, `darkTheme`) wrapped in `styled-components` `<ThemeProvider>`.
- Built interactive playground in `App.jsx` with real-time theme mode switching.
- Added master 404-line `AGENTS.md` and MIT `LICENSE`.
