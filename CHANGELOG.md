# Changelog

All notable changes to **Build 54 (Styled Components Theme-able UI Kit)** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.4.0] - 2026-07-31

### Added
- Integrated **Styled Segmented Control Switcher Component (`SegmentedControl.jsx`)**.
- Added compact horizontal view switcher with active pill surface backgrounds, option icons, size props (`sm`, `md`, `lg`), and `fullWidth` mode.

## [1.0.0] - 2026-07-30

### Added
- Initial release of **Build 54: Theme-able UI Kit using Styled Components (CSS-in-JS)**.
- Implemented **5 Core Theme-Aware Components** (`Button`, `Card`, `Badge`, `Switch`, `Input`).
- Implemented **Light / Dark Theme Tokens** (`lightTheme`, `darkTheme`) wrapped in `styled-components` `<ThemeProvider>`.
- Built interactive playground in `App.jsx` with real-time theme mode switching.
- Added master 404-line `AGENTS.md` and MIT `LICENSE`.
